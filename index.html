Panduan Penggunaan

1. Membuka Aplikasi:

  • Buka peramban (browser) Google Chrome di HP atau komputer Anda, lalu akses tautan aplikasi Buku Tamu WISTA.
  • Jika aplikasi sudah diinstal melalui menu Install App di peramban, cukup ketuk ikon aplikasi Buku Tamu WISTA langsung dari layar utama (home screen) perangkat Anda.

2. Mencatat Tamu Masuk:

  • Tekan tombol bulat bertanda (+) di pojok kanan bawah.
  • Waktu masuk terisi otomatis.
  • jika ingin mengedit WAKTU simpan data terlebih dahulu Baru bisa di edit.
  • Pilih nama Penerima. Ketik Nama Tamu,
  • jumlah Pengikut, Asal / Instansi, dan Keperluan.
  • Pilih Kamar (jika menginap) dan tambahkan catatan jika ada.
  • Tekan tombol SIMPAN DATA.
  • Jika data di EDIT Pastikan DATA Sudah benar sebelum di SIMPAN

3. Proses Check-Out:

  • Masuk ke menu Daftar Tamu.
  • Temukan tamu yang bersangkutan, lalu tekan tombol oranye Check-Out.
  • Maka Status Di sebelah nama Akan Berubah, Telan lagi untuk membatalkan

4. Mengelola Kamar dan Penerima

  • Ketuk ikon PENGATURAN di sudut kanan bawah navigasi.
  • Pilih menu Kelola Daftar Kamar untuk menambah atau menghapus kamar baru.
  • Pilih menu Kelola Penerima
    untuk menambah daftar nama orang yang bertugas menerima tamu.

5. Mengunduh Laporan:

  • Di menu Daftar Tamu, ketuk ikon Unduh di sebelah kiri atas.
  • Pilih format CSV atau XML untuk mengunduh rekap data.
Metode Sistem
Aplikasi ini berbasis Progressive Web App (PWA). Data disimpan secara lokal di perangkat agar tetap bisa diakses saat offline, dan otomatis disinkronkan ke Google Sheets saat terhubung ke internet.
Perhatian Penting
  • Pastikan indikator pojok kanan atas berstatus Online sebelum menutup aplikasi.
  • Jangan membersihkan data atau cache peramban saat status offline agar data aman.
