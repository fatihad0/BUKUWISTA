Cara Penggunaan Aplikasi
  • Tekan tombol melayang (+) di pojok kanan bawah untuk mencatat tamu baru.
  • Gunakan kotak Pencarian di menu Daftar Tamu untuk menemukan data spesifik dengan cepat.
  • Tekan tombol Check-Out pada kartu tamu jika kunjungan sudah selesai. Waktu keluar akan otomatis tercatat.
Metode yang Digunakan
Aplikasi ini dibangun menggunakan teknologi Progressive Web App (PWA). Sistem ini menyimpan data sementara di dalam perangkat Anda (Lokal/Cache) sehingga aplikasi tetap berfungsi penuh meskipun sedang Offline. Saat koneksi internet kembali aktif, data akan otomatis disinkronkan ke Google Sheets (Cloud).
Perhatian
  • Pastikan indikator di pojok kanan atas menunjukkan status Online atau Tersimpan sebelum Anda menutup aplikasi.
  • Jangan membersihkan (clear) data/cache browser Anda saat status masih Offline, karena dapat menyebabkan data tamu yang belum terkirim hilang permanen.
